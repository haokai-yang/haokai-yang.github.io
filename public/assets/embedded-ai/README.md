# Embedded AI project — media folder

Drop your images, videos, and other files here.

The project page (edited in `src/content.js`) references them by
paths like `assets/embedded-ai/demo.mp4`.

Suggested filenames the skeleton already has commented-out blocks for:
  device.jpg        # a nice hero photo of the finished thing
  internals.jpg     # showing the hardware layout / wiring
  demo.mp4          # main demo video
  demo_poster.png   # a still frame from the video (shown before it plays)
  shot_a.jpg        # for a side-by-side pair
  shot_b.jpg

You don't have to use those exact names — they're just what the
commented-out placeholders in `content.js` point at. Change either
side to match.
